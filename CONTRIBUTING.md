# Contributing to Smart Agriculture Assistant

Thank you for your interest in contributing to the **Smart Agriculture Assistant**!

## 🚀 How to Contribute

### 1. Reporting Bugs
- Check existing issues to verify the bug hasn't already been reported.
- Open a new issue with a clear title, description, steps to reproduce, and expected vs actual behavior.

### 2. Requesting Features
- Open an issue explaining the proposed feature and why it would be beneficial for farmers or researchers.

### 3. Submitting Pull Requests
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/your-feature-name`).
3. Make your changes and test them locally using `npm run dev`.
4. Ensure typescript passes without errors using `npm run lint`.
5. Commit your changes (`git commit -m 'feat: description of changes'`).
6. Push to your branch (`git push origin feature/your-feature-name`).
7. Open a Pull Request against the `main` branch.

## 🛠️ Code Guidelines
- Write clean, well-typed TypeScript.
- Follow Tailwind CSS utility patterns for UI components.
- Do not check in API keys or secret tokens. Use `.env.example` for documentation.
